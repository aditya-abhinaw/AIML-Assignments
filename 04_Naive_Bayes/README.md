# Assignment 4: Gaussian Naive Bayes Classification

## Aim
To implement the Gaussian Naive Bayes classification algorithm to predict student results.

## Objective
To classify students as Pass or Fail based on their study hours and attendance.

## Dataset
The dataset contains 15 student records with StudyHours, Attendance, and Result attributes.

## Methodology
1. Load the dataset using Pandas.
2. Separate input features and target labels.
3. Split the dataset into training and testing sets.
4. Train the Gaussian Naive Bayes model.
5. Predict student results and evaluate the model using accuracy, confusion matrix, and classification report.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn

## Result
The Gaussian Naive Bayes model achieved 80% accuracy on the test dataset.

## Conclusion
The experiment successfully demonstrated Gaussian Naive Bayes classification for predicting student results using study hours and attendance.
