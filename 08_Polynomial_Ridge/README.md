# Assignment 8: Polynomial Regression and Ridge Regression

## Aim

To implement Polynomial Regression and Ridge Regression for predicting salary based on work experience.

## Objective

To compare polynomial curve fitting with ridge regularization.

## Dataset

The dataset contains 10 records with Experience and Salary attributes.

## Methodology

1. Load the dataset using Pandas.
2. Separate the input feature and target variable.
3. Create a Polynomial Regression model of degree 2.
4. Create a Ridge Regression model with polynomial features.
5. Train both models on the dataset.
6. Evaluate the models using Mean Squared Error and R² score.
7. Plot the actual data and both regression curves.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Scikit-learn

## Result

Both Polynomial Regression and Ridge Regression models were trained successfully, and their predictions and evaluation scores were displayed.

## Conclusion

The experiment demonstrated polynomial curve fitting and the use of Ridge regularization in regression.
