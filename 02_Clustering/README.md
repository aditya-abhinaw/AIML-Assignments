# Assignment 2 - Clustering using Unsupervised Learning

## Aim

To apply clustering techniques using unsupervised learning.

## Objective

To group customers into different groups based on their annual income and spending score.

## Algorithm Used

K-Means Clustering

## Dataset

The dataset contains the following columns:

- CustomerID
- AnnualIncome
- SpendingScore

## Methodology

1. Load the dataset using Pandas.
2. Select AnnualIncome and SpendingScore for clustering.
3. Create a K-Means clustering model.
4. Divide the customers into 3 clusters.
5. Find the cluster centers.
6. Display the clusters using a scatter plot.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Scikit-learn

## Result

The K-Means algorithm successfully divided the customers into three different clusters based on their annual income and spending score.

## Conclusion

K-Means is an unsupervised learning algorithm used to group similar data points into clusters. In this assignment, customers were grouped based on their income and spending behavior.
