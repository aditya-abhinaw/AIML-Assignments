# Assignment 1: Association Between Dependent and Independent Variables

## Aim

To identify the association between dependent and independent variables using correlation analysis and linear regression.

## Objective

To study the relationship between the number of hours studied and the marks obtained by students.

## Variables

- Independent Variable (X): Hours Studied
- Dependent Variable (Y): Marks

## Dataset

The dataset contains two variables:

| Hours Studied | Marks |
|---:|---:|
| 2 | 45 |
| 3 | 50 |
| 4 | 55 |
| 5 | 60 |
| 6 | 65 |
| 7 | 72 |
| 8 | 78 |
| 9 | 85 |
| 10 | 90 |

## Methodology

1. Load the dataset using Pandas.
2. Separate the independent and dependent variables.
3. Calculate the correlation coefficient.
4. Calculate the linear regression line.
5. Visualize the relationship using a scatter plot and regression line.
6. Interpret the association between the variables.

## Result

The analysis shows a strong positive association between study hours and marks. As the number of study hours increases, the marks generally increase.

The scatter plot and regression line demonstrate this positive relationship.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib

## Conclusion

There is a positive relationship between the independent variable (Hours Studied) and the dependent variable (Marks). Therefore, students who study for more hours tend to obtain higher marks in this dataset.
