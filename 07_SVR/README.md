# Assignment 7: Support Vector Regression (SVR)

## Aim

To implement Support Vector Regression for predicting salary based on work experience.

## Objective

To understand how SVR models the relationship between experience and salary.

## Dataset

The dataset contains 12 records with Experience and Salary attributes.

## Methodology

1. Load the dataset using Pandas.
2. Separate the input feature and target variable.
3. Split the dataset into training and testing sets.
4. Standardize the input and target values.
5. Train the SVR model using an RBF kernel.
6. Evaluate the predictions using Mean Squared Error and R² score.
7. Plot the actual data and predicted regression curve.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Scikit-learn

## Result

The SVR model was trained successfully and generated salary predictions with a regression curve.

## Conclusion

The experiment demonstrated how Support Vector Regression can predict continuous values using a nonlinear regression model.
