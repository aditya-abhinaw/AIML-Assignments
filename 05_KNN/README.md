# Assignment 5: K-Nearest Neighbors (KNN) Classification

## Aim
To implement the K-Nearest Neighbors algorithm for classification.

## Objective
To predict whether a student will Pass or Fail based on study hours and attendance.

## Dataset
The dataset contains 20 student records with StudyHours, Attendance, and Result attributes.

## Methodology
1. Load the dataset using Pandas.
2. Separate input features and target labels.
3. Split the dataset into training and testing sets.
4. Standardize the input features.
5. Train the KNN classifier with 3 neighbors.
6. Evaluate the predictions using accuracy, confusion matrix, and classification report.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn

## Result
The KNN classifier was implemented to predict student results and evaluate its classification performance.

## Conclusion
The experiment demonstrated how KNN classifies data based on the nearest training examples.
