# Assignment 9: Object Detection using YOLO and OpenCV

## Aim

To implement object detection using YOLO and OpenCV.

## Objective

To identify and locate objects in an image using a pretrained YOLO model.

## Dataset

A sample street image containing people and vehicles is used as input.

## Methodology

1. Load the pretrained YOLO model.
2. Read the input image using OpenCV.
3. Perform object detection on the image.
4. Draw bounding boxes and labels around detected objects.
5. Display and save the output image.

## Technologies Used

- Python
- OpenCV
- Ultralytics YOLO

## Result

The program successfully detected people and cars and displayed their bounding boxes with confidence scores.

## Conclusion

The experiment demonstrated object detection using a pretrained YOLO model and OpenCV.
