# Assignment 10: Fake News Classification using TF-IDF and Logistic Regression

## Aim

To implement text classification using TF-IDF and Logistic Regression.

## Objective

To classify sample news headlines into Fake and Real categories.

## Dataset

The dataset contains 12 illustrative news text examples with their labels.

## Methodology

1. Load the dataset using Pandas.
2. Separate news text and labels.
3. Split the dataset into training and testing sets.
4. Convert text into numerical features using TF-IDF.
5. Train a Logistic Regression classifier.
6. Evaluate the model using accuracy, confusion matrix, and classification report.
7. Predict the category of a user-entered headline.

## Technologies Used

- Python
- Pandas
- Scikit-learn

## Result

The model successfully performed text classification. It achieved 33.33% accuracy on the small test set.

## Conclusion

The experiment demonstrated how TF-IDF and Logistic Regression can be used for text classification. A larger, verified dataset would be required for meaningful evaluation and reliable predictions.
