# Assignment 6: Linear Regression

## Aim
To implement Linear Regression for predicting student marks based on study hours.

## Objective
To understand the relationship between study hours and marks using a regression model.

## Dataset
The dataset contains 11 records with Hours_Studied and Marks attributes.

## Methodology
1. Load the dataset using Pandas.
2. Separate the input feature and target variable.
3. Split the data into training and testing sets.
4. Train the Linear Regression model.
5. Predict marks and evaluate the model using Mean Squared Error and R² score.
6. Plot the data and regression line.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn

## Result
The model generated predicted marks and achieved an R² score of 1.00 on the test set.
