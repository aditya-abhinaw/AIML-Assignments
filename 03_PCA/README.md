# Assignment 3 - Principal Component Analysis (PCA)

## Aim
To implement Principal Component Analysis for dimensionality reduction.

## Objective
To reduce the number of features in a dataset while preserving as much information as possible.

## Algorithm Used
Principal Component Analysis (PCA)

## Dataset
The dataset contains marks in Maths, Science, English, and Computer for eight students.

## Methodology
1. Create a dataset using Pandas.
2. Standardize the features using StandardScaler.
3. Apply PCA to reduce four features to two principal components.
4. Display the reduced dataset and explained variance ratio.
5. Plot the results using Matplotlib.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib

## Result
PCA successfully reduced the four subject features to two principal components and displayed the results graphically.

## Conclusion
PCA is a dimensionality reduction technique that transforms multiple features into fewer components while retaining as much variation in the data as possible.
